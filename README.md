# 🚗 운전면허 1종보통 학과시험 학습/모의시험

도로교통공단 **학과시험 문제은행(2026.3.9. 시행)** 의 965문제(동영상 문제 제외)로 공부하는 오프라인 웹 프로그램입니다.
설치 없이 **`index.html`을 더블클릭**해 브라우저로 열면 됩니다.

## 실행 방법
1. 이 저장소를 내려받습니다 (GitHub의 `Code → Download ZIP` 후 압축 해제, 또는 `git clone`).
2. 폴더 안의 `index.html`을 더블클릭합니다. (Chrome / Edge 권장)

## 기능
| 모드 | 내용 |
|---|---|
| 📘 학습 | PDF 순서대로 1~965번 출제. 보기를 고르면 **즉시 정답 + 해설** 표시. 마지막 위치 자동 저장, 번호·유형별(문장형/사진형/일러스트형/안전표지) 바로가기 |
| ❌ 오답노트 | 학습·모의시험에서 틀린 문제 자동 수집. 순서대로/섞어서 다시 풀기, 익힌 문제는 제거 |
| 📝 모의시험 | 랜덤 **40문제 · 40분 · 70점 합격**. 시험 중 정답·해설 비공개, 문항 번호판으로 이동, 시간 종료 시 자동 제출. 끝나면 점수·합격 여부·틀린 문제와 해설 확인 |

### 모의시험 구성 (실제 시험과 동일한 유형·배점)
| 유형 | 문항 수 | 배점 |
|---|---|---|
| 문장형 4지1답 | 17 | 2점 |
| 문장형 4지2답 | 4 | 3점 |
| 안전표지 | 5 | 2점 |
| 사진형 (5지2답) | 6 | 3점 |
| 일러스트형 (5지2답) | 7 | 3점 |
| 동영상 → 사진/일러스트형으로 대체 | 1 | 5점 |

> PDF에는 영상이 없어서 동영상 문제(966~1000번, 35개)는 학습·모의시험 모두에서 제외했습니다.
> 모의시험의 동영상 1문제(5점) 자리는 사진형/일러스트형 문제로 냅니다.

- 2개를 고르는 문제는 2개를 모두 맞혀야 정답으로 처리합니다.
- 진행 기록은 브라우저(localStorage)에 저장됩니다. 같은 PC, 같은 브라우저에서 이어서 할 수 있습니다.
- 키보드: `1~5` 보기 선택, `←/→` 이전/다음, `Enter` 정답 확인/다음 문제

## 구조
```
index.html            # 앱 (HTML/CSS/JS 단일 파일)
data/questions.js     # 문제 965개 (질문, 보기, 상황 설명, 정답, 해설, 그림 경로, 유형)
data/images/          # 사진형·일러스트형·안전표지 그림 (PDF에서 추출)
tools/parse_pdf.py    # PDF → data/ 변환기
question-bank.pdf     # 원본 문제은행
```

## 문제 데이터 다시 만들기 (문제은행이 개정됐을 때)
```bash
pip install pymupdf
python tools/parse_pdf.py question-bank.pdf
```
